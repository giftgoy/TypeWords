# 外刊资源与词典归属分析

## 入口和来源

「文章」页和资源市场新增「外刊资源」入口，直接地址 `/ebooks`。来源固定为 `giftgoy/awesome-english-ebooks`，目录快照版本 `c1b5c08aec4037c0c9ba3429540433003edcf6ed`。

原仓库当前有 163 个 EPUB 文件，其中一个目录夹带前一期副本，合并后提供 162 期：经济学人 97、纽约客 45、大西洋月刊 9、连线 11。显示封面日期，按日期排序，可搜索刊物或年月；不将封面日期当作文章发布日期，不擅自标注 CEFR 等级。

保留仓库来源和原始 EPUB、MOBI、PDF、音频清单链接，只展示来源实际提供的格式。正文版权仍归原权利人，仓库公开不代表杂志采用开源许可证。杂志内容和下载文件只存于本机缓存，不提交到本项目 Git 仓库。

## 阅读和加入书架

点击「下载并阅读」后，本机服务后台下载所选 EPUB，显示进度。按 EPUB spine 顺序提取正文，过滤导航页和无正文页，长篇按段落拆分为不超过 30000 字符的片段。解析结果是纯文本，不执行书中脚本、不加载外部图片或保留原始版式。

目录列出篇名和词数，可以逐篇阅读，沿用现有查词、释义和朗读功能。点击「将这篇加入文章书架」后保存为个人文章集；相同期刊、篇目 ID 去重，保留原有文章练习进度，不改变当前正在学习的书。可以在书架中继续阅读或跟打。

资源缓存位于现有数据卷的 `/data/ebooks`，按 Git blob SHA 校验和保存；章节缓存附解析器版本，重建容器可复用。查看/下载资源本身不改写学习数据库，只有用户主动加入书架才修改文章集。已有服务器学习备份包含加入书架的正文，原始 EPUB 缓存不进入学习数据 GitHub 备份。

目录以保存快照优先返回，超过六小时后后台检查更新，也可手动检查。网络故障保留旧目录；GitHub 匿名接口限流时显示原因并等待重试窗口，原始 EPUB 下载和已有缓存阅读仍可用。可选在 `deploy/.env` 设置 `EBOOKS_GITHUB_TOKEN` 并重建 data 服务，用于固定 GitHub API 的只读目录请求；无需为公开仓库授予写权限。密钥不发送给原始文件下载域名，也不返回到浏览器。

## 词汇所属词典

外刊阅读和现有沉浸阅读均提供「分析词典归属」。无需模型密钥，浏览器本地分析正文并匹配全部 14 本内置英语词典，以及有内容的个人词典/收藏等词表。

内置索引由 `node deploy/prepare-dictionary-membership.mjs` 从当前词典目录生成，Docker 构建时自动重新生成。索引保留一个词的全部词典成员，不把重叠词强行划入单一词典。

正文先按大小写归一的英文词形统计词次与去重数量。每个词典内优先记原词命中，未直接命中的词典可显示规则还原候选；保留多个可能原形并标明对应词典。用户可以关闭候选，仅统计原词命中。词形候选是匹配线索，不冒充语境词义消歧。

词典卡显示收录词形数、出现词次、原词与候选数量。可按词典、匹配类型和词形/原形筛选，逐词查看全部归属和频次，包含未收录项。统计按文中词形去重，词典之间有重叠，数量不能相加；未收录不等于高级词，可能是专名、新词或词库覆盖不足。多词短语的整体归属不在本次单词统计范围内。

## 验证

- Node 测试验证词次、重叠词典、不规则词形、歧义候选、仅原词模式、个人词典合并、生成索引与原始词典一致。
- Python 测试验证 EPUB 顺序、重复/导航过滤、主动内容剥离、路径越界、长文不丢词、缓存复用、资源 API、学习数据隔离和跨站请求拒绝。
- 实际下载并解析四类刊物各一期；浏览器在独立测试数据库验证阅读、归属筛选、导入书架及刷新恢复。生产学习记录不混入这些测试数据。
