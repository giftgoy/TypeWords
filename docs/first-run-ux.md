# 首次使用与本地部署体验

本次修复对应十项体验问题：

| 项目 | 当前行为 |
| --- | --- |
| 首次进入 | 不自动压暗页面。单词页提供主动开始引导入口；每一步都有关闭和跳过。 |
| 引导进度 | 共用五步定义，分母由步骤数生成。最终一步高亮 `#word-wrap`。帮助、通用设置和单词页可重看。跳过、关闭、刷新不会把未完成引导记为完成。 |
| 资源数量 | 首页读取真实目录数量；当前提供 14 本词典，与资源市场一致。未加载完成时不展示虚构数量。 |
| 学习设置 | 用户看到的起点从第 1 词算起，存储仍沿用零基索引。直接调整每天的新词数和每组复习上限，说明只安排到期词。设为 0 时暂停复习，也支持复习数少于新词数。 |
| 练习列表 | 默认收起；进入不超过 1439 像素宽的练习页时也会收起旧设置里的展开状态。提供明确的“展开练习列表”按钮。 |
| 发音失败 | 捕获媒体播放拒绝、加载失败、语音服务失败和无响应；优先在线发音，再尝试浏览器语音。失败保留可见提示，提供重试、声音设置、听写时不计错查看单词。过期回调不会影响新词。 |
| 资料入口 | 默认真实链接在新标签页打开，扫码是单独的可选操作。标明网盘可能需要登录；本地部署隐藏官方小程序推广。 |
| 复习术语 | 统一为“智能复习（FSRS）”。错误阈值、记忆率和权重收进高级设置；学习记录跳转到真实的单词页日历。 |
| 收藏提醒 | 练习中不再自动弹收藏提示。帮助页显示当前部署地址并说明 Ctrl+D / Command+D。 |
| 空任务 | 开始按钮使用原生禁用语义，并在页面说明没有到期词、复习上限为 0 或全部被过滤等原因。存在可练词时提供自由练习；生成任务的入口也检查空任务。 |

自动测试：`pnpm test`，包含引导状态、单词编号、零任务、复习上限、部署识别和发音恢复，以及原有资源与过滤测试。

浏览器验证使用独立测试源站，覆盖完整五步引导、跳过后重看、1366×768 下首次练习、静音听写时不计错显示单词、全词过滤后的空任务，以及无到期任务时进入自由练习。用户的本地正式版学习记录未用于这些测试。
